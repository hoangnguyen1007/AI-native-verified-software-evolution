## Labels, accounting and adjudication

- A structural label specifies subject, scope, kind, direction and status; source history labels cite exact Git blob bytes and line/structure evidence. A README, issue or commit message can guide discovery but is never the oracle. A historical change with build drift establishes scoped declaration/observation changes; it need not establish exact binding or causal evolution. Never claim passive/native equivalence. An independent reviewer checks labels and production results at G7; writing labels before engine output is independence from the implementation, not independent human review.
- Region vectors in the registry are exhaustive small-world oracles. Index 0 is `w0`, then `w1` and so on. Enumerate all 16 quantifier pairs by the Cartesian product of the four specified vectors; assign each case ID `E06-<left>-<right>` and expected intersection membership by the per-world truth table in the registry. Kc is fully feasible and aligned unless stated otherwise. T/F/U vectors, not engine outputs, determine labels. The normalized comparison quantifier uses complete T/F coverage; preserve native classifications independently (explicit and symbolic M4 providers do not always aggregate unknown worlds the same way). Empty/unknown feasibility cases are separate, not vacuously true. Replay side-specific witness and counter-witness operands. Treat `UNSAT` as proof only with its validated input/region; use UNKNOWN for timeout/exhaustion.
- Record expected, observed and adjudicated rows by case/capability; distinguish `PASS`, `FAIL`, `UNSUPPORTED`, `NOT_RUN`, `CENSORED`, `DISPUTED` and `NOT_APPLICABLE` with reasons. Count both side censuses, selected and not selected contexts, ambiguous and unavailable candidates, all missing obligations, true/false/unknown/side-only region populations where countable, and provenance/redaction failures. Do not count unavailable labels as TN. A bounded fixture checks fixture scope; unlabeled repository observations are not precision/recall labels.
- Freeze acceptance criteria now for exact controls: all registered gate-critical positive/negative outcomes match, zero false certain correspondence, false resolution or silent omission, and all emitted definite witnesses replay at their claimed tier. Report TP/FP/FN and precision/recall by applicable family with denominators (undefined when denominator zero), region cardinality accuracy only where measurable, and symbolic equivalence/inclusion separately. All UNKNOWN is a failure on positive controls. Every case stays accounted for, including not run and disputed. Existing Track A recovery `950‰` is not a delta accuracy threshold.

Start with the [existing M9 single-job development profile](../m9/PROTOCOL.md) (JDK 21, 2 GiB heap, one process/job, workspace outside Git/Z:; 300 s per observation as an allocation). The historical larger profile (8 GiB heap, 12 GiB process working-set stop, 8 GiB scratch, 1,800 s) is available only if justified by a measured M11 pilot and physical headroom; no new SLA or product admission threshold. Choose/pin actual environment and allocations before scoring and never tune them on acceptance outcomes. Reuse the existing 33k-node generator family for bounded scale; add high evidence/degree, many-context and interrupted workloads only where they test the affected contract. Do not rerun reserved large/native campaigns merely to expand counts.

Use one pilot on development inputs to estimate phase limits, then three fresh cold-process comparisons (empty derived comparison index, same immutable inputs/cache) and three warm comparison queries (existing verified index, force actual recompute for any warm compare claims; exclude result reuse hits or measure separately). OS cache is uncontrolled. Report per-phase wall time (verify/index/align/delta/publish/first page/later page), peak process-tree working set with sampling interval and omissions, heap limit, peak scratch, page bytes/rows and canonical digests. Report samples/median/range; no tail latency claim from six runs. Stop at actual resources or watchdog, retain censored outcome and verified checkpoint, and test retry/restart and tampering. A changed wall time or transport page size must not change a completed canonical result over fixed inputs/work policy. A censored prefix cannot be substituted for a complete result.

Freeze the M11 candidate and exact paired artifact inputs before acceptance. Keep labels/registrations append-only after freeze; explain any prospective change, preserve failed/censored runs and adjudicate disagreements independently of output.
