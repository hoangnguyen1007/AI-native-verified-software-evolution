These preferences do not constitute usability/performance gate evidence. The additive CLI adapter `architecture.cli:m7.2-v1` remains **PROVISIONAL** pending product acceptance.

## Responsibilities and alternatives

The new `cli` module is a composition root over existing acquisition/frontend/pipeline, stable query/metrics/policy/assessment services and the in-process M7.1 JSON adapter. It depends on the `backend` JAR for reusable JSON/report dispatch, but starts no HTTP server and requires neither a backend service nor Neo4j. Domain objects and arithmetic stay in `analyzer`; parser objects remain in the JavaParser adapter. An adapter response, not a terminal table, owns canonical values, evidence, status and identities.

Picocli 4.7.7 handles parsing, usage and Bash completion; a metadata-derived PowerShell completion generator handles command/option names. A Java 21 shaded JAR and thin Windows/POSIX launchers are the reversible distribution baseline. A raw-screen JLine/Lanterna application and a native executable were alternatives; neither is necessary for the human-selected scrollback palette. Replace the line-input boundary when validated terminal UX requires history/fuzzy completion, and replace distribution when a registered installation/startup requirement justifies native packaging. This is a routine adapter choice, not a change to the parser, graph store or score model approval.

`EvoApp` owns commands, explicit selection and composition. `TerminalReports` supplies command-specific inventory bars, directed path/dependency diagrams, numbered rows, rule/finding summaries, metric operands, evidence sufficiency and bundle/witness details. `--details` expands canonical fields. `TerminalView` owns localized presentation, terminal-control sanitization, conservative Unicode width handling and ANSI policy. `TerminalSession` owns native Windows console preparation, measured startup window width and restoration, through an encapsulated Jansi 2.4.2 JNI adapter. It enables/verifies processed-output/VT flags and UTF-8 output before rendering, then restores original mode/code page on normal exit or JVM shutdown. Failed native access/VT verification yields plain output even when color was requested; explicitly colored redirected output remains possible. No global stream rewriting is installed, preserving canonical machine bytes. `Workspace` owns bounded strict-UTF-8 input, validated content-addressed graph/policy storage, atomic selection pointers and create-only export output. `Exports` projects already-computed results into SARIF/GraphML without inventing findings or metrics. `EvoMain` owns process streams/exit status. No target source, build file or command operand is evaluated as shell code.

## Selection, completeness and replay

Graph/context discovery precedes querying. A single analysis partition may be selected automatically; several partitions require an exact context or displayed index. One selected context is never a universal repository or multi-build result. MAY/MUST/UNKNOWN/realized/union projections and population/limit inputs use M5/M7.1 requests. Union is visibly exploratory. Full request files may carry all canonical filters and budgets; conflicting direct flags are rejected. All 22 M7.1 operations and six report operations remain available through `query` even when no dedicated alias exists.

Human output may condense lists of evidence references and source metadata, while explicitly exposing status, reported gaps, bounds, result identity and continuation. Canonical JSON is unchanged. Missing score/policy/snapshot is an actionable error or a domain-withheld result, never a fabricated zero or healthy assessment. Policy evaluation retains NEVER/UNKNOWN rule rows. Assessment is obtained from M6 with the approved baseline parameters through the existing candidate-model constructor; its emitted calibration marker is preserved.

Human inventory rows persist exact references bound to graph/context/scope. Palette `next` retains the exact validated wire request/cursor, immutable graph and published report for the current page; it does not reread mutable request files or resolve numbered operands again. Other commands invalidate it; language/help preserve it. Semantic query overrides are rejected. Canonical JSON still retains its complete cursor. Both `show` and `evo show` are accepted by the palette without shell evaluation. Names/digest prefixes are conveniences over stable entity queries. A complete bounded lookup must identify one observed entity; ambiguity, an open denominator or unfinished page requires an exact ID or a saved numbered row. No type, coordinate or semantic target is guessed. `witness` supplies the Evidence Bundle including original predicate/request, regions and witnesses. `replay` evaluates that predicate against the same canonical graph/context; this remains formula replay rather than fresh Spring execution.

## Passive scan and remaining boundary

The scan adapter records a selected local repository, finite acquisition limits, explicit JDK/release/UTF-8 fallback policy, exclusions and every pipeline issue/gap. It uses verified JDK symbols, passive Maven modeling and the existing UniversalArchitecturePipeline. Defaults are explicit analysis policy, not inferred repository truth. The CLI does not inspect ambient Maven settings, discover/deploy services, execute target lifecycles, acquire dependencies over the network or assert Spring container membership without evidence. Richer exact-classpath/configuration snapshots remain importable. Broader evidence-provider setup and policy-qualified impact associations are remaining M7 workflow acceptance work, not claims of this CLI slice.

The source selector `cli.source-selection:v1` excludes recorded build/cache/test/unrelated paths without following links or interpreting `.gitignore`. A successfully modeled Maven root additionally narrows inputs to declared source roots. `--include-tests`, `--all-files` and explicit exclusions are recorded policy. `MavenScan` uses the existing passive effective-model/local-classpath providers against an explicit cache or the default local Maven repository. Exact available artifact bytes/order are hashed; no ambient settings, network access or target execution is involved. Missing reactor binaries and incomplete generated/plugin evidence remain gaps. Definite captured handwritten sources survive those qualifications through `source.universal-ingestion:m7.2-qualified-sources-v1`.

A real self-scan exposed compiler plugin version metadata being interpreted as a compiler argument. `build.maven-model:3.9.16-m7.2-compiler-bindings-v1` uses actual compiler parameter/property bindings; unsupported real arguments remain explicit. JavaParser shared local variable type nodes are coalesced by written site and owner before mapping, preserving distinct field/parameter owners. A dedicated JLS 3.3 translation map preserves raw UTF-16 spans across Unicode escapes, ordinary backslashes and CR/LF; malformed eligible escapes produce typed source errors while valid siblings survive. The frontend version below covers these repairs.

Large graphs use streaming canonical hashing, snapshot serialization and strict UTF-8/canonical decoding. The codec still rejects duplicate keys/rows, malformed encoding, noncanonical bytes and digest/reference mismatches. Auxiliary `frontend.result-index:m7.2-v1`, `ingestion.outcome-index:m7.2-v1` and `evidence.ledger-index:m7.2-v1` avoid embedding full duplicated populations; original individual records, identity/order references and full gap provenance remain in the graph. A reconstruction regression proves frontend payload equality. Inventory metrics support both historical full frontend payloads and the new index. These content changes naturally create new graph identities; snapshot wire schema and M1 formulas are unchanged.

CLI snapshots have explicit 1,000,000,000 byte/character, depth 128 and 16,000,000 JSON-value ceilings; query/export output remains 32 MB. Launchers allow a 4 GiB JVM heap. The palette caches one verified immutable selected graph, invalidated by scan/open; context changes update only selection metadata. Failed terminal scans never replace a usable selection. Build output isolation and a packaged-class/journey smoke prevent IDE error stubs from silently entering the distributed JAR.

An integration test exposed a pre-existing adapter rejection of valid JMODs containing only a module descriptor. The repair validates that descriptor and contributes an empty type solver while retaining the original hashed artifact in the manifest. Descriptor-less/corrupt archives still fail. Frontend provider `frontend.javaparser:3.28.2-m7.2-written-types-v2` records this behavior change. Constructor-site ingestion explicitly accepts that compatible provider and advances to `spring.constructor-ingestion:m7.2-written-types-compat-v2`; unregistered providers remain unknown. This does not certify JPMS resolution.

Actual-source CLI verification also exposed declaration bodies in the existing public `spelling` field. Query/evidence views now retain only identifier-like Java spelling and preserve canonical names, IDs, spans and immutable underlying evidence. Query version advances to `architecture.query:m7.2-v2`, with synchronized OpenAPI/version assertions; prior cursors/requests must be recomputed. Validated module/source-document relative labels and manifest partition metadata make contexts readable without exposing host paths or arbitrary configuration values. Provenance reads context evidence with bounded gap qualification, without constructing an unrelated entity inventory. Graph schema, M1 identity preimages, policy/metric/score formulas and historical evidence are unchanged.

## Interoperability, safety and limits

JSON retains M7.1 envelopes and result digests. SARIF 2.1.0 maps observed findings/severity/source coordinates while carrying complete canonical findings/evaluation in properties, preserving conditional qualification, provenance and incomplete denominators. GraphML contains one bounded directed edge page plus its complete canonical response as graph metadata; edge records retain region/support/classification data. Neither format changes unknowns into absence. JSON and export serialization are bounded; oversize output fails before publication, rather than truncating semantic records. File output is create-only.

Input paths reject symbolic-link ancestors; snapshots are verified through GraphSnapshotCodec/FileGraphStore. Repository acquisition has its existing no-follow/hash/attempt contracts. Query metadata remains redacted by stable services. Source/configuration bytes intentionally retained in local snapshot/policy storage are not reclassified as redacted exports. Local mutable selection is atomic; snapshots/policy content are immutable and verified. Terminal controls, bidi/format controls and newlines in untrusted labels are rendered as visible escapes. Machine output remains free of ANSI and locale-dependent formatting.
